# AVIALOG — Inteligência de transporte

Sistema de planejamento e análise logística do transporte de aves.

## Versão portátil

Abra a pasta `AVIALOG_PORTATIL` e execute `INICIAR.bat` no Windows ou `iniciar.sh` no Linux. Requer Python 3.9 ou superior.

## Código-fonte

O projeto completo está em `AVIALOG_PROJETO`. Consulte `LEIA-ME.txt` e `AVIALOG_PROJETO/README_AVIALOG.md` para orientações.

Os dados iniciais são de demonstração. O banco de dados local é criado durante o uso e não é versionado.
